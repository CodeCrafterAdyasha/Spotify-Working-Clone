# 🎧 Spotify Working Clone

A **Spotify-inspired music player web application** built using **HTML, CSS, and JavaScript**.  
This project replicates the basic look, feel, and functionality of Spotify’s web player, allowing users to play songs with an interactive and responsive UI.

---

## 🚀 Project Overview

The **Spotify Working Clone** is a front-end web project created to practice web development concepts such as UI design, audio handling, and JavaScript DOM manipulation.  
It demonstrates how a music streaming interface works at a basic level.

---

## ✨ Features

- 🎶 Spotify-like user interface
- ▶️ Play and Pause songs
- ⏭️ Next / Previous track controls
- 🎵 Song list with selectable tracks
- 📊 Progress bar to track song duration
- 🎧 Smooth and responsive design
- 📱 Works on different screen sizes

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Music control logic and interactivity
